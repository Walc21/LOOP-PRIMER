# Protocolo para Gemini

Leia e cumpra `AGENTS.md` integralmente; ele é a política canônica deste
repositório.

Antes de analisar, planejar ou alterar arquivos, execute na raiz:

```bash
python3 scripts/ai_context.py
```

Depois, leia `AI_CONTEXT.md` integralmente. Registre o encerramento somente
após a última edição e validação, conforme `AGENTS.md`.
